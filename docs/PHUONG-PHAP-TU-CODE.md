# Phương pháp tự phát triển

1. Đọc tài liệu và API chính thức để rút ra nguyên tắc.
2. Xác định hợp đồng dữ liệu riêng: Project, Scene, Character, Shotlist.
3. Tự viết API, giao diện và kiểm định, không fork trộn nguồn.
4. Chỉ tạo adapter đến engine bên ngoài, có cấu hình thay thế.
5. Duy trì kiểm thử và tài liệu về giới hạn kỹ thuật.
6. Ghi phiên bản model, nguồn media, giấy phép, quyền sử dụng trước khi xuất bản.

**Phân biệt rõ:** fingerprint dữ liệu ≠ khóa danh tính khuôn mặt; xuất MP4 tiêu đề ≠ sinh cảnh phim AI; API adapter ≠ workflow GPU đã nghiệm thu.
